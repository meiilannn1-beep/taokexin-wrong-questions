# 陶可馨 · 高考错题学习站

这是一个支持多设备登录的高考错题复习网站。家长和妹妹分别登录后，看到的是同一套错题、学习计划和知识点数据。

## 功能

- 每日学习计划监控：到期错题自动排入当天计划，支持手动添加任务和一键生成建议计划。
- 遗忘曲线复习：按“第 1、2、4、7、15、30 天”安排复习，测试后根据记忆质量自动调整下一次复习时间。
- 错题本：记录题目、答案、解析、错误原因、难度、来源、标签、关联知识点和错题图片。
- 知识图谱：内置九大学科示例知识点，可编辑、新增、删除。
- 错题知识点总结：自动统计薄弱知识点，并生成可复制的复习报告。
- 学情分析：各学科错题分布、掌握度分布和近 14 天复习趋势。

## 本地运行

安装依赖：

```bash
cd "C:\Users\Lenovo\Documents\ChatGPT\陶可馨错题集"
python -m pip install -r requirements.txt
```

启动：

```bash
python app.py
```

打开 `http://localhost:8000`，首次使用请先点“创建账号”注册。

## 首次注册

注册时需要填写家庭邀请码，默认是：

```text
taokexin2026
```

家长和妹妹可以分别注册两个账号，登录后共用同一份学习数据。修改邀请码可在启动服务时设置环境变量：

```bash
# Windows PowerShell
$env:INVITE_CODE="你的家庭邀请码"
$env:SECRET_KEY="请设置一个足够长的随机字符串"
python app.py
```

## 发布到网上，让妹妹在平板上登录

代码已经准备好部署，推荐使用 Render 的免费方案：

1. 把整个文件夹上传到 GitHub。
2. 打开 [Render](https://render.com/)，选择 **New → Blueprint**。
3. 选择这个仓库，项目里已经提供了 `render.yaml`。
4. 部署完成后，Render 会给你一个类似 `https://xxx.onrender.com` 的网址。
5. 在 Render 的环境变量里设置：
   - `SECRET_KEY`：一个足够长的随机字符串。
   - `INVITE_CODE`：你们家庭的邀请码。
6. 把网址发给妹妹，在平板浏览器打开后，添加到主屏幕即可像 App 一样使用。

也可以部署到 Railway、Fly.io、自己的 VPS，或任何支持 Python + Gunicorn 的平台。启动命令是：

```bash
gunicorn app:app --bind 0.0.0.0:$PORT
```

## 数据存储

- 登录账号和错题数据保存在服务器端的 SQLite 数据库 `instance/txk.db` 中。
- 本地运行时，`instance/` 目录会在第一次启动时自动创建。
- 发布到免费托管平台时，免费实例的磁盘可能会重置，建议定期备份 `instance/txk.db`，或后续把数据库换成 PostgreSQL。
